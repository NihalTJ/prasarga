🤖 Social Media OS Integration

Connect to your Social Media OS platform for automated scheduling, cross-platform posting, and engagement management.

⚪ Checking...
The base URL where your Social Media OS is hosted.
This must match the API key configured in your Social Media OS.
The endpoint on Social Media OS that receives video content.

📋 How Integration Works

  1. Generate a video in the Create tab
  2. Click "Send to Social Media OS"
  3. Social Media OS receives the video URL, topic, caption, and metadata
  4. It adapts the caption per platform (X, Instagram, YouTube, Facebook)
  5. It schedules and posts at the optimal time for each platform
  6. Performance data flows back to the Social Media OS dashboard

⚙️ These settings are configured in your .env file as:
SOCIAL_OS_ENABLED=true
SOCIAL_OS_URL=https://your-social-os.up.railway.app
SOCIAL_OS_API_KEY=your-shared-secret
SOCIAL_OS_INGEST_ENDPOINT=/api/content/ingest
